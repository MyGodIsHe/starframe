# Security Policy

## Supported Version

Only the current `main` branch is supported. Starframe is an experimental
client-side application and does not process EVE credentials or personal data.

## Reporting a Vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/MyGodIsHe/starframe/security/advisories/new)
for vulnerabilities that should not be disclosed publicly.

Include the affected revision, reproduction steps, expected impact, and any
suggested mitigation. Do not open a public issue until the report has been
reviewed and a disclosure timeline has been agreed.
